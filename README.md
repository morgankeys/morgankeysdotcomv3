# morgankeysdotcomv3

## Overview
This repo contains the code for my personal portfolio site. It is also based of my personal prototyping-kit template. The template defines high-level organizational structure, along with template files for skills and documentation. 

Work is organized into four top-level, peer folders:

| Folder     | Purpose                                                                    |
| ---------- | ------------------------------------------------------------------------- |
| `Code/`    | The entire codebase for the prototype being built.                        |
| `Docs/`    | Human-level documentation and resources.                                  |
| `Export/`  | Built versions of the prototype, staged for manual transfer to a server. |
| `Agents/`  | Instructions, skills, context, and prompts for AI agents (this material). |

## Philosophy and workflow
The Code folder keeps techncial details separate from skills, content, and supporting materials. Ideally, the Code could be completely wiped and rebuilt without distrubing contextual materials.

The Agents folder should evolve skills with learnings and optimizations over time. The Docs folder will keep source-of-truth copies of things like design system data and content. 

The Export folder is mostly intended for builds and exports in work environments. It's usefulness here it TBD.
